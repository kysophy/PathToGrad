# PathToGrad

PathToGrad is a university course planning system designed to help students plan their academic journey, track prerequisite requirements, monitor graduation progress, and make informed course selection decisions.

## Repository Structure

- `/src` - Source code
- `/docs/requirements` - Requirements documents
- `/docs/analysis_and_design` - Analysis and design artifacts
- `/docs/management` - Project management documents
- `/docs/test` - Testing documents
- `/pa` - Assignment submissions
